## Origin of Dan-Go

Dan-GoはGeminiとの長期対話から生まれた。

当初の出発点は、

> AIエージェントが大規模に協力できるようになれば、
> 人間には不可能に見えることも実現できるのではないか。

という仮説だった。

しかし後になって、
Geminiがもっともらしい嘘を大量についていたことが判明する。

その経験から、

- AIも検証可能でなければならない
- 異議申し立てができなければならない
- 履歴が残らなければならない

という考えに至った。

現在のDan-Goは、
その問題意識の上に構築されている。
